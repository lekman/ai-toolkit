# Docs

Cross-cutting concepts that span more than one practice: shared mental models,
not per-practice instructions (those live with each practice). A folder of
_meaning_, not a dumping ground for prose by _medium_.

- [CONTRIBUTING.md](CONTRIBUTING.md): how to work in this repo, covering where
  things go, commits, branches, linting, and how packages are built and released.
- [principles.md](principles.md): the concerns behind the practices (the _why_).
- [controls.md](controls.md): soft (advisory) vs hard (enforced) vs boundary
  controls; why an agent may edit some things but not others.
