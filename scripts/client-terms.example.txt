# Terms that must never appear in this public repository.
#
# One POSIX extended-regex per line. Matched case-insensitively. Blank lines
# and lines starting with # are ignored.
#
# Copy to scripts/client-terms.txt and fill in the real values. That file is
# GITIGNORED on purpose: a committed list of client names is the leak the
# check exists to prevent.
#
# What belongs here — anything that identifies an engagement:
#   - client and employer names, and their common short forms
#   - their repository names
#   - their tracker project keys
#   - product, service and internal system names
#   - counterpart organisations named in meeting titles
#
# Keep the list in sync across every machine that does client work. A term
# missing here is a term the hook will let through.
#
# Examples, replace with your own:

# acme-corporation
# \bACME\b
# acme-platform
# PROJ-[0-9]+
# some-internal-service
